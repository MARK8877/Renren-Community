# CreatorHub 开发版本规划

> 面向开发人员。本文只说明各版本要开发的页面、页面功能、状态和跳转关系。

## 1. 公共约定

### 1.1 底部导航

```text
首页｜社区｜发布｜消息｜我的
```

### 1.2 用户角色

| 角色 | 权限 |
|---|---|
| 普通用户 | 浏览、互动、发布、关注、加入社区/群聊、私聊 |
| 创作者 | 普通用户权限 + 创作者中心、粉丝群、数据和收益 |
| 社区主理人 | 创建和管理社区、群聊、成员及管理员 |
| 社区管理员 | 管理被授权的社区内容、成员和群聊 |
| 平台管理员 | 使用 Web 管理后台 |

### 1.3 通用状态

所有列表页必须处理：加载中、空数据、加载失败、重新加载、下拉刷新、分页和无更多数据。

所有提交操作必须处理：防重复提交、成功提示、失败原因、重试、登录失效和无权限提示。

内容状态：

```text
草稿 → 审核中 → 已发布
              ↘ 审核不通过
已发布 → 已删除/已下架
```

# 2. MVP

## 2.1 目标和范围

完成主流程：

```text
注册 → 选择兴趣 → 浏览内容 → 关注创作者
→ 加入社区/讨论群 → 群聊或私聊 → 创作者继续发布
```

MVP 不开发支付、订阅、打赏、活动、积分、直播、电商和 AI。

## 2.2 启动、登录和新用户引导

### 启动页

- 展示 Logo。
- 检查本地 Token。
- 未登录跳转登录页。
- 已登录但未完成兴趣选择，跳转兴趣选择页。
- 已完成引导，跳转首页。

### 登录页

**页面元素**

- 手机号/邮箱、验证码或密码输入框。
- 获取验证码、登录、注册按钮。
- 用户协议和隐私政策勾选框。
- 第三方登录入口。

**功能**

- 校验手机号或邮箱格式。
- 获取验证码并显示倒计时。
- 未勾选协议不能登录。
- 登录成功保存 Token 和用户信息。
- 登录失败显示服务端原因。
- 连续失败时按服务端规则限制重试。

**跳转**

- 未完善资料 → 资料设置页。
- 未选择兴趣 → 兴趣选择页。
- 已完成引导 → 首页。

### 注册页

- 手机号/邮箱注册。
- 获取并验证验证码。
- 设置密码。
- 确认年龄。
- 同意协议后提交。
- 注册成功跳转资料设置页。

### 资料设置页

- 上传头像。
- 设置昵称和个人简介。
- 校验昵称长度、重复和敏感词。
- 保存后跳转兴趣选择页。

### 兴趣选择页

- 展示兴趣标签。
- 至少选择 3 个。
- 支持选择和取消。
- 保存后跳转推荐关注页。

### 推荐关注页

- 展示推荐创作者和社区。
- 关注/取消关注创作者。
- 加入/退出社区。
- 点击卡片进入对应主页。
- 点击完成进入首页。

## 2.3 首页和内容消费

### 首页

**顶部**：关注、推荐、热门三个 Tab，搜索和通知入口。

**Feed 卡片**

- 展示视频或图文、作者、标题、摘要、话题和发布时间。
- 点赞/取消点赞。
- 评论、收藏/取消收藏、分享。
- 关注/取消关注作者。
- 点击作者进入创作者主页。
- 点击内容进入详情页。
- 展示关联社区或讨论群入口。
- 不感兴趣和举报。

**数据规则**

- 关注：只返回已关注创作者内容。
- 推荐：按兴趣和用户行为返回。
- 热门：按服务端热度排序。
- 被删除或下架的内容不能返回。
- 关注列表为空时展示推荐创作者。

### 视频播放页

- 自动播放、暂停、进度显示和上下滑切换。
- 点赞、评论、收藏、分享和关注。
- 显示作者、标题、描述和话题。
- 点击作者进入创作者主页。
- 显示加入社区或讨论群按钮。
- 已加入时显示进入社区或群聊。
- 记录曝光、播放时长、完播和互动事件。
- 播放失败显示重试。

### 图文详情页

- 展示作者、时间、图片、标题、正文和话题。
- 点赞、评论、收藏、分享和关注。
- 加入关联社区或讨论群。
- 展示评论列表和相关推荐。

### 评论列表/弹层

- 按热度或时间展示评论。
- 发布评论、回复评论、点赞评论。
- 删除自己的评论。
- 举报评论。
- 作者关闭评论后禁止输入并显示提示。

## 2.4 搜索

### 搜索页

- 搜索框和搜索历史。
- Tab：综合、内容、用户、社区、群聊。
- 综合页混合展示各类型结果。
- 点击结果进入内容详情、用户主页、社区详情或群资料页。
- 支持清除单条/全部搜索历史。
- 无结果时展示空状态。

## 2.5 内容发布

### 发布类型选择页

- 拍摄视频。
- 上传视频。
- 发布图片/图文。
- 发布动态。
- 未授权相机/相册时提示授权。

### 视频编辑发布页

- 视频预览和上传进度。
- 上传失败后重试。
- 设置封面、标题和描述。
- 添加/删除话题。
- 选择社区，可不选。
- 讨论群：不绑定、选择已有群、创建新群。
- 设置可见范围：公开、关注者、仅自己。
- 设置评论权限：所有人、关注者、关闭。
- 保存草稿或提交审核。
- 发布后状态为审核中，审核通过后才进入 Feed。

### 图文编辑发布页

- 上传、删除和排序图片。
- 输入标题和正文。
- 添加话题和选择社区。
- 绑定或创建讨论群。
- 设置可见范围和评论权限。
- 保存草稿或提交审核。

### 创建讨论群页

- 上传群头像。
- 设置群名称、简介和规则。
- 群类型：公开群、申请群、粉丝群。
- 创建成功后自动绑定当前内容。

### 我的内容管理页

- Tab：已发布、审核中、未通过、草稿。
- 查看内容和状态。
- 编辑草稿。
- 查看审核不通过原因。
- 删除内容前二次确认。

## 2.6 社区

### 社区首页

- Tab：我的社区、推荐、热门、分类。
- 社区搜索入口。
- 展示头像、名称、简介和成员数。
- 加入/退出社区。
- 点击进入社区详情。

### 社区详情页

**顶部**

- Logo、背景图、名称、简介、成员数和在线人数。
- 加入/退出、分享、举报按钮。
- 公告和规则入口。

**Tab**

- 热门、最新、精华：展示社区内容 Feed。
- 群聊：展示社区下的群。
- 成员：展示成员和创作者。

**状态**

- 申请加入时显示等待审核。
- 退出社区前二次确认。
- 未加入用户的浏览、发帖和聊天权限由社区配置决定。

### 创建/编辑社区页

- 上传 Logo 和背景图。
- 设置名称、简介、分类、公告和规则。
- 设置公开加入或申请加入。
- 保存并提交平台审核。
- 审核通过后才可搜索和推荐。

### 社区管理页

- 编辑资料、公告和规则。
- 审核加入申请。
- 查看、禁言或移除成员。
- 设置/取消社区管理员。
- 查看、删除或设为精华的社区内容。
- 管理社区群聊。

## 2.7 群聊

### 群聊列表页

- 展示已加入群聊。
- 展示最后消息、时间和未读数。
- 按最后消息时间排序。
- 点击进入群聊。

### 群聊页

- 消息类型：文字、图片、视频、表情、平台内容卡片。
- 发送和接收消息。
- 加载更早消息。
- 回复、@成员、复制和撤回消息。
- 举报消息。
- 展示发送中、成功、失败状态；失败可重试。
- 展示未读消息分割线。
- 被禁言时禁止发送并显示禁言时间。
- 点击顶部进入群资料页。

### 群资料页

- 展示群头像、名称、简介、成员数、公告和规则。
- 查看成员和邀请用户。
- 退出群聊。
- 管理员可修改资料、审核申请、禁言、移除成员和设置管理员。

### 群加入逻辑

| 群类型 | 处理 |
|---|---|
| 公开群 | 点击加入后直接成为成员 |
| 申请群 | 提交申请，管理员同意后加入 |
| 粉丝群 | 已关注者直接加入；未关注者先提示关注 |

## 2.8 私聊和消息

### 消息中心

- 私聊和群聊会话列表。
- 展示头像、名称、最后消息、时间和未读数。
- 按最后消息时间排序。
- 互动消息、新关注和系统通知入口。
- 支持全部标记已读。

### 私聊页

- 发送文字、图片、视频、表情和内容卡片。
- 加载历史消息。
- 显示消息发送状态，失败可重试。
- 点击头像进入用户主页。
- 举报或拉黑对方。
- 拉黑后双方不能继续发送消息。

### 消息请求页

- 陌生人首次私信进入消息请求。
- 用户可接受、拒绝、举报或拉黑。
- 接受后生成正常会话。
- 拒绝后不生成正常会话。

### 互动通知页

- 展示评论、回复、点赞和关注通知。
- 点击跳转对应内容或用户主页。
- 内容已删除时显示内容不存在。

### 系统通知页

- 展示审核结果、违规处理和平台公告。
- 审核不通过通知跳转内容管理页查看原因。

## 2.9 用户、创作者和“我的”

### 用户主页

- 展示头像、昵称、简介、关注数、粉丝数和获赞数。
- 关注/取消关注和发起私聊。
- 展示作品和动态。
- 举报或拉黑用户。
- 本人查看时显示编辑资料。

### 创作者主页

- 包含用户主页全部功能。
- Tab：作品、动态、社群。
- 加入粉丝群按钮。
- MVP 不展示支付入口。

### 关注/粉丝列表页

- 展示关系用户。
- 关注/取消关注。
- 点击进入用户主页。
- 分页加载。

### 我的页面

入口：个人主页、我的作品、收藏、点赞、关注、粉丝、我的社区、创作者中心、设置。

### 编辑资料页

- 修改头像、昵称和简介。
- 校验昵称长度、重复和敏感词。

### 隐私设置页

- 谁可以私信：所有人、关注我的人、互相关注、关闭。
- 谁可以评论。
- 关注列表和粉丝列表是否公开。
- 是否显示在线状态。

### 通知设置页

- 评论、点赞、关注、私信、群聊和系统通知开关。

### 黑名单页

- 展示已拉黑用户。
- 解除拉黑。

### 账号安全页

- 修改密码。
- 绑定/更换手机号或邮箱。
- 退出登录。
- 注销账号。

## 2.10 MVP 创作者中心

### 创作者中心首页

- 今日播放量、新增粉丝数和内容数。
- 内容管理、数据中心、社群管理入口。

### 内容数据页

- 按内容展示播放、点赞、评论和收藏数。
- 展示关注人数和关注转化率。
- 展示讨论群点击、加入人数和加群转化率。
- 按时间范围筛选。

### 粉丝数据页

- 粉丝总数、新增粉丝数和趋势。
- 按时间范围筛选。

### 社群管理页

- 展示创作者创建或管理的社区和群聊。
- 跳转社区管理页或群资料页。

## 2.11 MVP Web 管理后台

### 后台登录页

- 管理员账号密码登录。
- 登录失败限制重试。
- 按角色加载菜单权限。

### Dashboard

- 新增用户、活跃用户、发布量、审核量和举报量。
- 内容到社区/群聊的转化数据。

### 用户管理页

- 按用户 ID、手机号、昵称和状态搜索。
- 查看用户资料、内容、社区和处罚记录。
- 禁言、封禁和解除处罚。
- 记录操作管理员和时间。

### 内容审核页

- 按待审核、已通过和已拒绝筛选。
- 查看内容、作者和关联社区/群聊。
- 通过、拒绝或下架内容。
- 拒绝和下架必须填写原因。

### 社区管理页

- 审核新社区。
- 查看和修改社区状态。
- 下架违规社区。

### 群聊管理页

- 搜索和查看群聊。
- 查看成员和举报记录。
- 禁用违规群聊。

### 举报管理页

- 按待处理、处理中和已完成筛选。
- 查看举报对象、原因、证据和历史。
- 选择处理结果并填写说明。
- 处理结果通知相关用户。

### 运营配置页

- 管理兴趣分类和话题。
- 配置推荐创作者、推荐社区和热门内容。

## 2.12 MVP 开发顺序

1. 用户、角色、登录和权限。
2. 兴趣、社区、话题、内容、群聊数据模型。
3. 视频/图文上传、审核、详情和 Feed。
4. 点赞、评论、收藏、关注和分享。
5. 社区列表、详情、加入和管理。
6. 内容绑定社区和讨论群。
7. 群聊、私聊、消息请求和通知。
8. 用户主页、创作者主页和“我的”。
9. 创作者数据。
10. 管理后台、举报、风控和埋点。

## 2.13 MVP 验收

- 新用户能完成注册、资料和兴趣选择并进入首页。
- 用户能浏览、发布和互动视频/图文。
- 内容审核通过后显示；拒绝后作者能看到原因。
- 用户能从内容加入社区或讨论群。
- 群聊和私聊消息可发送、接收、撤回和重试。
- 陌生人消息必须经过消息请求。
- 举报能在后台完成查看、处理和留痕。
- 创作者能查看内容、粉丝和加群转化数据。

# 3. V1.0

## 3.1 目标

增加创作者收费、收益结算、群聊增强和社区运营功能。

## 3.2 支付和付费页面

### 支持创作者页

- 展示打赏和订阅入口。
- 展示订阅价格和权益。
- 已订阅用户显示到期时间和管理入口。

### 打赏确认页

- 选择固定金额。
- 展示创作者、金额和支付方式。
- 创建订单并调用支付。
- 支付成功后通知创作者。
- 重复支付回调不能重复入账。

### 创作者订阅页

- 展示月度价格和会员权益。
- 支付成功后发放会员内容、会员群和徽章权益。
- 到期后自动失效。
- 展示当前状态和到期时间。

### 付费内容详情页

- 未购买用户只显示试看内容。
- 点击解锁进入订单确认页。
- 支付成功后显示完整内容。
- 已购买用户不能重复购买。
- 退款后按规则回收权益。

### 付费群详情页

- 展示价格、有效期、简介和规则。
- 支付成功后自动加入群聊。
- 权益到期后移出或限制访问。
- 成员权限必须以服务端订单权益为准。

### 用户钱包页

- 展示余额、充值、提现和交易记录。
- 交易按类型和时间筛选。
- 显示处理中、成功和失败状态。

### 订单确认/支付结果页

- 展示商品、收款方、价格和支付方式。
- 防止重复提交。
- 处理成功、失败、取消和超时。
- 最终结果以服务端订单状态为准。

## 3.3 创作者收费和收益页面

### 付费内容设置页

- 设置价格和试看比例。
- 显示平台抽成和预计收入。
- 发布前校验创作者认证和收款状态。

### 订阅设置页

- 设置月度价格和权益说明。
- 选择会员内容和会员群。
- 开启或关闭订阅。

### 收益中心

- 今日、本月和累计收益。
- 待结算和可提现金额。
- 按打赏、订阅、付费内容、付费群筛选明细。
- 提现入口。

### 提现页

- 绑定收款方式。
- 输入提现金额。
- 校验可提现余额和最低金额。
- 展示审核中、处理中、成功和失败状态。
- 失败资金退回可提现余额。

### 高级数据中心

- 内容：曝光、播放、观看时长、完播、互动、收益。
- 粉丝：新增、趋势、活跃度、兴趣分布。
- 社群：成员、新增、DAU、消息数、活跃用户。
- 收益：收入类型、付费人数和转化率。
- 支持时间筛选。

## 3.4 群聊增强

### 群聊页新增

- 语音消息、文件、投票、公告、置顶、精华消息和聊天搜索。

# 4. V2.0

## 4.1 目标

增加实时音视频、课程、品牌广告、电商和 AI 辅助功能。

### 语音房

# 5. 版本依赖和不做项

```text
MVP：用户/内容/社区/群聊
            ↓
V1.0：订单/支付/权益/收益
            ↓
V2.0：实时互动/商业生态/AI
```

- 内容绑定讨论群依赖内容、社区、群聊和权限模型。
- IM 依赖消息存储、未读数、离线消息和推送。
- 支付依赖实名、订单、账本、权益、结算和风控。
- 直播依赖实时音视频、审核、举报和高并发。
- AI 依赖内容权限、审核、隐私和成本控制。
- 不为不同兴趣分类开发不同代码；所有兴趣共用一套社区功能。
- 不做 Tinder 式照片匹配。
- 积分不直接兑换现金。
- 不自动发布 AI 生成内容。
