# CreatorHub 完整功能列表

> 文档版本：V1.0
>
> 产品范围：内容社区 + 创作者经济 + 兴趣社交 + IM 即时通讯
> 说明：仅整理既有 PRD 已讨论功能，不扩展其他项目。

## 1. 标注规则

### 1.1 优先级

| 优先级 | 定义 |
|---|---|
| P0 | 核心链路或安全/账务底座，所属版本缺失则不可发布 |
| P1 | 版本重要能力，直接影响核心体验与目标达成 |
| P2 | 增强体验、运营效率或增长能力 |
| P3 | 后期扩展能力，需在前置闭环稳定后建设 |

### 1.2 用户角色

- 普通用户：浏览、互动、发布、加入社区/群聊及付费支持。
- 创作者：普通用户能力 + 创作者主页、粉丝/社群经营与收益能力。
- 社区主理人：创建社区、规则、成员、内容、群聊和活动管理。
- 社区管理员：被授权的部分社区和群聊管理能力。
- 平台管理员：Web Admin 中的审核、运营、财务、风控和数据管理。

## 17. 明确排除或延后事项

| 事项 | 处理结论 |
|---|---|
| 11 个兴趣分别开发 | 不做；统一复用分类、社区、话题、内容、群聊结构 |

| 积分直接兑换现金 | 不做；避免刷量和财务风险 |
| 直播/音视频房提前上线 | 不做；留至 V2.0 |
| 广告、品牌、电商提前上线 | 不做；用户与商业化闭环稳定后进入 V2.0 |
